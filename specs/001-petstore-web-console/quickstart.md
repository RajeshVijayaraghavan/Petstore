# Quickstart: Petstore Web Console

**Feature**: 001-petstore-web-console  
**Date**: 2026-03-22

## Prerequisites

- Node.js 20+ (LTS)
- npm 10+ or pnpm 9+
- A modern browser (Chrome, Firefox, Safari, Edge)

## Project Setup

```bash
# 1. Scaffold the project with Vite + React + TypeScript
npm create vite@latest petstore-console -- --template react-ts
cd petstore-console

# 2. Install core dependencies
npm install react-router-dom @tanstack/react-query \
  react-hook-form @hookform/resolvers zod zustand \
  react-oidc-context oidc-client-ts

# 3. Install Tailwind CSS v4
npm install tailwindcss @tailwindcss/vite

# 4. Install shadcn/ui CLI and initialize
npx shadcn@latest init

# 5. Install dev dependencies
npm install -D orval msw vitest @testing-library/react \
  @testing-library/jest-dom @playwright/test
```

## API Client Generation

```bash
# Generate typed API client + TanStack Query hooks from the OpenAPI spec
npx orval --config orval.config.ts
```

The Orval config should point to `https://petstore3.swagger.io/api/v3/openapi.json` and output to `src/api/`.

```bash
npx playwright test
```

## Key Integration Points

1. **API Client**: All API calls go through Orval-generated hooks (e.g., `useFindPetsByStatus`, `usePlaceOrder`). These wrap TanStack Query and handle caching, loading, and error states automatically.

2. **Authentication**: The `AuthProvider` (from `react-oidc-context`) wraps the app. Protected routes check auth state. The API client attaches the session token as `api_key` header.

3. **Forms**: Pet create/edit and order placement use React Hook Form with Zod schemas generated by Orval. Validation matches the API contract.

4. **Error Handling**: A global error boundary catches unhandled errors. API errors are mapped through `error-mapper.ts` to user-friendly messages.

5. **Testing**: Orval generates MSW handlers from the spec. Integration tests use these mocks for realistic API simulation without a backend.

## Screen Navigation Flow

```
Login ──→ Pet Catalogue (default)
              │
              ├──→ Pet Detail ──→ Edit Pet
              │         │
              │         └──→ Place Order ──→ Order Confirmation
              │
              ├──→ [Navbar] Inventory Dashboard
              │         └──→ Click status → Pet Catalogue (filtered)
              │
              ├──→ [Navbar] Orders ──→ Order Lookup ──→ Cancel Order
              │
              └──→ [Navbar] Users (admin only) ──→ Create/Edit/Delete User
                    │
                    └──→ Logout → Login
```
